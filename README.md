A responsive recreation of the uploaded 15.37-second screen recording.

## Visible elements recreated

- Dark near-black page background.
- Blue heading: **Lamp Toggle Login Form**.
- Hanging lamp with dark shade, glowing yellow bulb and pull cord.
- Soft triangular yellow light beam.
- White login panel beneath the lamp.
- **Welcome** heading.
- **Email Address** and **Password** fields.
- Yellow **Sign In** button.
- Lamp ON/OFF states that change the light beam and the login card brightness.

## Project files

- `index.html` — semantic markup for the lamp and login form.
- `style.css` — lamp drawing, beam/glow, card styling, responsive layout and ON/OFF transitions.
- `script.js` — lamp toggle and demo form submission.
- `README.md` — project instructions.

## Run

No package installation or build step is needed.

1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` using Live Server, or open it directly in a modern browser.
4. Click the lamp to turn the light ON/OFF.
5. Enter an email and password to test the demo submit message.

## Source fidelity

The recording shows the rendered interface and a small code pane, but the original source text is too small to transcribe reliably line-for-line. This project recreates the visible layout and toggle behavior as a complete runnable implementation. Sign In is a frontend demo; no real authentication service is connected.
